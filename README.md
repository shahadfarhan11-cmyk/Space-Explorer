🚀Space Explorer – Interactive 3D Solar System
🌌About the Project
Space Explorer is an interactive educational web application that allows users to explore the solar system in 3D, discover fascinating facts about planets, and test their astronomical knowledge through interactive quizzes.
The application supports both Arabic and English, providing an engaging bilingual learning experience.
✨ Features:
- Interactive 3D solar system exploration.
- Discover information and facts about the Sun and all eight planets.
- Arabic and English language support.
- Interactive knowledge quizzes.
- Instant answer feedback and score tracking.
- Achievement badges based on quiz performance.
- 3D camera controls, zooming, and planet selection.
- Responsive interface for different screen sizes.
🛠️Technologies Used
- HTML5
- CSS3
- JavaScript
- Three.js
🎯 Project Purpose
Designed to make learning about astronomy more engaging through interactive 3D visualization and educational activities.

🚀 مستكشف الفضاء – النظام الشمسي التفاعلي ثلاثي الأبعاد

يدعم التطبيق اللغتين العربية والإنجليزية لتوفير تجربة تعليمية ممتعة.
✨ المميزات:
- استكشاف تفاعلي للنظام الشمسي بتقنية 3D.
- التعرف على الشمس والكواكب الثمانية.
- دعم اللغتين العربية والإنجليزية.
- اختبارات تفاعلية لقياس المعرفة.
- عرض الإجابات الصحيحة والخاطئة واحتساب الدرجات.
- شارات إنجاز حسب نتيجة الاختبار.
- إمكانية تحريك المشهد والتكبير واختيار الكواكب.
- واجهة متجاوبة مع مختلف أحجام الشاشات.
🛠️ التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript

 🎯 هدف المشروع
